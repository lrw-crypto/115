# 草商探索趣

**今天，換你當草商新生！**

以「探索學校、體驗科別、發現興趣」為方向的校園探索遊戲。訪客直接點選建築或探索護照的科別，即可認識課程、體驗約一分鐘的小任務，不需要操控角色走到門口。

## 啟動

```sh
cd /workspace/115
python3 -m http.server 8000 --bind 127.0.0.1
```

靜態 HTML / CSS / JavaScript，沒有 npm 安裝、建置、外部 CDN 或登入需求。網站由 `.github/workflows/pages.yml` 於 main 更新後自動發布至 https://lrw-crypto.github.io/115/ 。

## 畫面與互動

校景依使用者提供的草屯商工校園位置圖及建築參考發展：紅磚／米白校舍、藍灰斜屋頂、玻璃中庭、中央草地、走廊、操場與入口。科別位置是遊戲導覽配置，**並非實際教室定位圖**；未使用海洋或分散島嶼。畫面為原創等角 SVG 插畫，非可自由旋轉的 WebGL 模型。

20 位藍白制服 Q 版學生沿校園步道圖移動，NPC 中鼎文戴「客服」髮箍、騎滑板車沿走廊巡遊。角色、護照按鈕均可呼叫客服與獎品說明。全場可暫停，尊重 prefers-reduced-motion；分頁隱藏與任務視窗開啟時不推進位置。

校外保留萊爾富及右側南臺灣土魠魚羹，均為想像配置，不表示真實店址；魚羹店商標是依提供圖樣重繪的 SVG，可點店面放大。

## 八種小任務

| 科別 | 體驗 |
| --- | --- |
| 會計事務科 | 將三筆校園小店紀錄分為收入／支出，答錯可重試 |
| 商業經營科 | 比較水壺的醒目／遮擋陳列效果，選擇合適設計 |
| 資料處理科 | 排列方向指令，執行並讓學生走到星星；可退一步／重排 |
| 應用英語科 | 替早上到訪的外國訪客選一句歡迎用語 |
| 機械科 | 將底座、齒輪、轉軸放到對應位置；支援拖曳，也支援點選零件再點位置 |
| 配管科 | 旋轉四個管線圖塊，接通起點與終點 |
| 綜合職能科 | 點掉三團泡泡，完成服務車清潔 |
| 普通體育班 | 選擇暖身準備，再依序點亮節奏點 |

任務為認識科別的簡化情境，不是專業實作程序、安全訓練、測驗成績或資格認證。錯誤操作不扣分，可重試。完成顯示「你認識了這個科別！」，本科首次完成獲得金幣一枚。

## 探索護照與實體獎品

localStorage 的 `caotun-island-exploration-v1` 僅儲存已完成科別 ID，保留舊版已收集金幣；刻意保留歷史鍵名以免遺失進度。八科最多八枚，已完成科別可重玩但不重複給幣。不儲存任務操作或個人資料，不跨裝置同步；清除網站資料會重設。儲存被禁用時退回頁面記憶並提示。

使用者已選擇**校方提供的實體小禮物**，但領取規則尚未提供。中鼎文顯示「領取辦法待公告」，集滿後保留八枚、不扣除，不發放兌換序號或領取資格。本機紀錄可修改，正式發放前需依校方規則補上適用的資格確認與兌換紀錄。沒有數位紀念卡取代實體禮物。

## 校園動態與 TA bot

## 驗證

```sh
python3 tests/validate_curriculum.py
# 另需已備妥 Playwright 與 Chromium，並先啟動靜態伺服器：
CAMPUS_BASE_URL=http://127.0.0.1:8000/ node tests/browser-campus-game.cjs
```

可用 `CHROMIUM_PATH` 指定瀏覽器路徑。前者檢查原件與資料一致性、八科班總學分、469 列六學期與頁碼、代表課程；後者實際操作八個任務，驗證錯誤重試、拖曳／手機點選、指令執行、重玩防重領、舊版進度保存、校景／角色／客服、暫停及手機版。舊版海面、快艇、偏好問答的瀏覽器測試已由新校園遊戲測試取代。

## 依參考圖製作馬卡龍粉色校景

校景改為參考圖的斜向鳥瞰配置：左後方橢圓操場、後方活動中心、中央玻璃樓、左右教室與三合院庭院、縱向中央草地、前方半圓頂涼亭花園、校門及周邊道路／斑馬線。校外左邊保留南臺灣土魠魚羹及使用者提供的商標描圖，右邊保留萊爾富。各科位置是遊戲導覽分配，不能作正式教室定位。

`assets/campus-macaron.png` 為依使用者參考圖生成的原創場景插畫（1536 × 1024，約 3 MB），使用草莓牛奶粉、蜜桃粉、鐵深灰斜屋頂、奶油白校舍與薄荷綠草地。背景不含靜態人物；學生、客服 NPC 由 SVG 即時繪製，制服與材質保留，學生新增六種表情並在換路線時隨機變換；中鼎文的髮箍與滑板車造型保留。插畫以完整影像載入；放大採圖像縮放，非可旋轉的即時 3D 模型。

`assets/campus-map.js` 的建築多邊形、科別標籤、校門招牌、店家商標與步道節點，共用插畫座標再轉換為 SVG 座標。以正門往內看、由近到遠計算樓棟：左一為綜合職能；左二共用會計事務、商業經營、資料處理；右二為應用英語；機械與配管分別位於使用者標示的藍框校舍、紅框校舍，兩科各有獨立建築入口。右一與中央玻璃棟不放科別指標。科名可直接進入，共用建築則先選科別；操場保留體育班入口。角色從整個校園道路網隨機選目的地，涵蓋草地步道、操場、左側校內道路和校外人行道路，經校舍／警衛室後方時使用插畫片段遮擋。八科任務、舊版金幣及護照資料保留。

`assets/campus-layout.css` 保留大圖與精簡護照版面，新增粉色介面樣式，不改角色材質。手機預設近看，可拖曳，或按「全景」查看整個校園。`tests/browser-campus-layout.cjs` 驗證插畫載入、實際屋頂點選／鍵盤／標籤入口、店家、步道路線連通、客服原造型、分散散步、表情變化、掃地動畫與手機拖曳／全景。完整闖關仍使用 `tests/browser-campus-game.cjs`。

校門依提供照片改為通暢的開放車道、左右收合的伸縮門、右側警衛室及斜側木格柵校名。地圖名牌只顯示「中鼎文」，頭頂保留「客服」；點開的標題為「校園客服-中鼎文」。

`assets/groundskeeper-cat.png` 為依使用者貓咪參考圖生成的透明角色素材，搭配獨立 SVG 掃把持續掃地。貓固定在中央草地（`CAMPUS_CAT_POINT`），不參與學生尋路；點選或鍵盤啟動會顯示拿著掃把的貓與對話泡泡「阿樺大哥又割草了」；地圖與對話共用同一組角色及掃把圖案。暫停動態、開視窗、切離地圖、分頁不可見或減少動態偏好，都會暫停掃地動畫。

## 清楚的科別介紹與貼地移動

科別介紹參考使用者提供的虎尾資工畫面：一句話入門、四個可展開的學習重點、興趣標籤，再保留完整專業與實習課程。參考網址在此環境無法連線，採提供截圖的呈現方式，不挪用其大學課程內容。八科白話說明與課名均依草商原始 115 入學計畫整理，每個重點附對應 PDF 課程連結。手機主要說明至少 17px，桌機 18px；資料與來源保留為次要層級。

從地圖、科名或護照選科，先用 620ms 拉近該棟校舍，再開介紹；關閉時回到原視角。新的操作、搜尋、Escape 或切頁可取消尚未完成的拉近；減少動態偏好會直接開介紹。

屋頂改為鐵深灰，維持原粉色校舍和其他配置。步道路線移除穿越玻璃樓與屋頂的捷徑。角色走曲線、以弧長及幀時間前進並加減速；學生的左右腳、手臂跟隨實際移動距離，腳底與固定地面影子分開。中鼎文沿左側校內道路騎行，輪底貼地、有輻條的輪子隨里程轉動，遇學生減速／停讓；學生繞行也不會在換向或到站時瞬移。人物依腳底深度排序；校舍遮擋、暫停動態及減少動態偏好維持。

```sh
CAMPUS_BASE_URL=http://127.0.0.1:8000/ node tests/browser-campus-reading-motion.cjs
```

門口花園原本的雙圓環雕塑，已依提供的實景照片改為白色半圓頂、環形樑及圓柱支撐的開放式涼亭造型，保留既有花園位置與周邊配置。
