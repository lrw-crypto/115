# 草商探索趣

**今天，換你當草商新生！**

以「探索學校、體驗科別、發現興趣」為方向的校園探索遊戲。訪客直接點選科別名稱方塊或探索護照的科別，即可認識課程、體驗約一分鐘的小任務，不需要操控角色走到門口。

## 啟動

```sh
cd /workspace/115
python3 -m http.server 8000 --bind 127.0.0.1
```

靜態 HTML / CSS / JavaScript，沒有 npm 安裝、建置、外部 CDN 或登入需求。網站由 `.github/workflows/pages.yml` 於 main 更新後自動發布至 https://lrw-crypto.github.io/115/ 。

## 畫面與互動

校景依使用者提供的草屯商工校園位置圖及建築參考發展：紅磚／米白校舍、藍灰斜屋頂、玻璃中庭、中央草地、走廊、操場與入口。科別位置是遊戲導覽配置，**並非實際教室定位圖**；未使用海洋或分散島嶼。畫面為原創等角 SVG 插畫，非可自由旋轉的 WebGL 模型。

20 位藍白制服 Q 版學生沿校園步道圖移動，NPC 中鼎文戴「客服」髮箍、騎滑板車沿走廊巡遊。角色、護照按鈕均可呼叫客服與獎品說明。全場可暫停，尊重 prefers-reduced-motion；分頁隱藏與任務視窗開啟時不推進位置。

校外保留萊爾富及右側南臺灣土魠魚羹，均為想像配置，不表示真實店址；魚羹店商標是依提供圖樣重繪的 SVG，可點店面放大。

## 八種小任務

| 科別 | 體驗 |
| --- | --- |
| 會計事務科 | 將三筆校園小店紀錄分為收入／支出，答錯可重試 |
| 商業經營科 | 比較水壺的醒目／遮擋陳列效果，選擇合適設計 |
| 資料處理科 | 排列方向指令，執行並讓學生走到星星；可退一步／重排 |
| 應用英語科 | 替早上到訪的外國訪客選一句歡迎用語 |
| 機械科 | 將底座、齒輪、轉軸放到對應位置；支援拖曳，也支援點選零件再點位置 |
| 配管科 | 旋轉四個管線圖塊，接通起點與終點 |
| 綜合職能科 | 點掉三團泡泡，完成服務車清潔 |
| 普通體育班 | 選擇暖身準備，再依序點亮節奏點 |

任務為認識科別的簡化情境，不是專業實作程序、安全訓練、測驗成績或資格認證。錯誤操作不扣分，可重試。完成顯示「你認識了這個科別！」，本科首次完成獲得金幣一枚。

## 學生走路與路線除錯

`assets/campus-navigation.js` 集中管理插畫上的地面節點、連線、可行走範圍與花台／警衛室等障礙。所有點都由原圖 1536 × 1024 座標轉成同一個 SVG 世界座標。角色預留半徑 10 個世界單位，障礙使用圓與多邊形邊界距離檢查；路段每 0.5 單位取樣並額外留 0.35 安全距離。樹旁路線會沿空曠的草地邊緣小幅繞行，避開花台，不穿越整片中央草地。校內與校外只經正門連通；看不清開口的操場不添加假出口，也不選跨區目的地。

`assets/campus-life.js` 使用唯一的 requestAnimationFrame 迴圈與 1/120 秒固定模擬步長。30、60、144 Hz 都以實際經過時間前進，切換分頁、暫停或重新初始化會清除舊時間／動畫迴圈。彎道先檢查角色寬度，必要時縮小圓角；在路線準備時建立弧長與曲率資料、快取曲線，幀內不重新找路或掃描建築多邊形。接近彎道與目的地會減速、起步加速；目的地先分散／預約，窄路跟隨前方學生，斑馬線盡頭避免多人同時停留。

學生仍是原本制服與表情的 SVG。雙腿移出上半身的起伏群組，用連接髖部的腿線、襪子、鞋子獨立動作，步伐依實際里程推進；站立、暫停及減少動態偏好均停止踏步。腳底為定位點，陰影固定在地面，身體起伏不超過 0.18 個角色局部單位。建築與必要的樹木遮罩使用原圖局部複製，依腳底深度與學生排序；人物／陰影／遮罩／除錯圖都不攔截建築點擊，原背景檔案未修改。

除錯預設關閉，沒有正式介面按鈕。開發時可在網址加 `?routes=1`，或於瀏覽器主控台執行：

```js
setCampusRouteDebug(true);  // 範圍、障礙、路線、節點、每名學生的腳底與寬度
setCampusRouteDebug(false);
validateCampusNavigation(); // 應回傳 []；修改地圖後先檢查每段連線
```

新增 `tests/browser-campus-walking.cjs`：檢查可到達的有向路線、彎道／直線的角色寬度、校門拓撲、三個種子各 300 秒且每幀 20 人的越界／瞬移／朝向／重疊統計，並比較 30／60／144 Hz 的模擬結果。另在即時畫面觀察 32 秒，檢查腳步、站立、暫停／恢復、分頁可見性事件、地圖拖曳縮放／重設、重複初始化、手機、照片介紹和原有金幣流程。

```sh
CAMPUS_BASE_URL=http://127.0.0.1:8012/115/ node tests/browser-campus-walking.cjs
```

需先啟動靜態伺服器，並提供 Playwright 與 Chromium。測試的分頁隱藏／返回使用可見性事件模擬，手機使用 Chromium 視窗模擬；未包含真實手機、Safari 或不同實體螢幕實測。

### 修正跑道／中央大樓前方人物被截斷

建築的遮擋深度改為插畫遮罩本身的下緣，移除原本額外向下延伸的 24 個原圖像素。這個延伸曾使操場後方跑道、中央玻璃大樓前步道上的人物仍排在建築後面，造成頭部／身體被截掉。學生路線、速度及樹木遮擋維持；實際在建築後方時仍正常遮擋。

`tests/browser-campus-occlusion.cjs` 在八個桌機路線位置與三個手機位置，將正常畫面與暫時隱藏遮罩的參考畫面逐張比較 PNG 像素，確認前方人物沒有被抹去；另檢查真正後方的遮擋保留。

## 應用英文科大樓前的新角色

`assets/campus-visitor.js` 新增依使用者參考造型設計的條紋衫角色：禿頭、黑框眼鏡、黃領紫色條紋上衣、牛仔褲與深色鞋。地圖角色固定站立，只有頭部每三秒輕輕左右搖一次；對話使用依參考圖製作的透明哭哭人像 `assets/crying-visitor.png`；文字為真正的 HTML，完整對白是「我沒吃鳳梨跟芒果呀!」。

角色固定在 `CAMPUS_VISITOR_HOME_NODE`（應用英語科／應用英文科的 `right-2` 大樓前步道），不再尋路或走動。`campusVisitorHeadAngle` 在第 3、6、9…秒開始短暫搖頭，身體、雙腳與陰影保持原位；沿用現有動畫時鐘，不另開計時器。保留原有 20 名學生、中鼎文、掃地貓、課程介紹與進度；與角色對話不會發幣。支援點選、Enter／空白鍵、Esc 關閉和焦點返回；暫停散步、開啟視窗、切換分頁與減少動態時停止搖頭。

`tests/browser-campus-visitor.cjs` 檢查 120 秒模擬中角色保持固定、實際觀察第 3／6 秒搖頭且雙腳不動、共用暫停、桌機／手機對話、哭哭人像載入、逐字對白、進度不變與重新初始化不重複建立角色。


### 學生避開固定角色

固定角色的站位現在也是學生路網中的障礙。`campusFixedResidentBounds` 依角色的身體寬度／高度，加上學生自身寬度，保留不接觸的矩形範圍；出生點、停留點、路線連線、平滑彎道及每個模擬步長都會檢查。狹窄步道被站位占用時，學生改選同一可到達區域內的其他目的地，不穿過角色，也不為了繞行穿越花圃或建築。每個區域保留至少一個空的停留點，避免所有學生互相等候而卡住。

固定角色仍在原位，每三秒搖頭，哭哭對話不變。開啟 `?routes=1` 才會看到金色禁入範圍；正式畫面不顯示。

`tests/browser-campus-visitor-clearance.cjs` 以三個種子各模擬 300 秒，檢查學生從出生到停留均未進入禁入範圍，並定期比較實際 SVG 人物身體的畫面範圍，確保沒有接觸／重疊；同時確認每人持續完成行程、固定角色不移動、最後一層逐步防撞保護及手機對話正常。既有路線測試改以可到達區域為準，不再假設所有同類步道都能穿過角色站位互通。


### 加油角色與清楚的探索護照

`assets/campus-supporter-original.jpg` 保留使用者上傳的原圖（157 × 400）。`assets/campus-supporter-cutout.png` 是依原圖去除白色背景的透明版本，保留短髮、圓框眼鏡、白上衣與黑裙的 3D Q 版造型。地圖與對話共同使用此透明 PNG，SVG 使用 `preserveAspectRatio="xMidYMax meet"`，對話依圖片原始比例縮放並使用 `object-fit: contain` 與自動長寬比，避免拉伸；`assets/campus-visitor.js` 的 `CAMPUS_SUPPORTER_POINT` 設定站位（原固定角色旁），`CAMPUS_SUPPORTER_LINE` 設定「加油!加油!」對白。沿用共用視窗、鍵盤與焦點返回，對話不影響金幣。兩位固定角色都納入路網與每步移動的避讓檢查，除錯模式會顯示兩個禁入區。

`assets/campus-layout.css` 最後的護照樣式集中控制字級、配色與手機排版：科名 16px、任務狀態 13px、標題 24px，使用深紫文字與粉色卡片；完成項目為深綠文字、綠色底與勾號。桌機護照加寬為 280px，手機窄螢幕單欄排列，版面高度隨內容延伸，避免放大文字被裁掉。

`tests/browser-campus-supporter-passport.cjs` 檢查新角色對白／固定位置／焦點、護照字級與對比、窄手機不溢出、科名方塊可互動而背景不觸發介紹。`tests/browser-campus-visitor-clearance.cjs` 也檢查學生不與兩位固定角色重疊。

頁首標語「今天，換你當草商新生！」位於品牌名稱之後，品牌採用鮮明粉紅／橘色／藍綠漸層；手機將標語換到品牌下方。地圖上方不再提供分類列，八科方塊全部顯示。版面樣式在 `assets/campus-layout.css` 最後一段，頁首內容在 `index.html`。

### 草稿：玩家角色與多指縮放

`assets/campus-player.js` 管理男／女生角色、暱稱（最多 12 字）與 `caotun-player-v1` 本機儲存；金幣仍沿用既有儲存鍵。科別、護照、課程卡與搜尋結果均先導引至 `CAMPUS_PLAYER_STOPS` 的探索入口，再開啟原有介紹和遊戲。取消按鈕或 Esc 會停在當下位置；改選目的地從所在路段的可達端點續行，不跳回上一個節點。操場等不相通路網保留轉場提示。

`assets/campus-gestures.js` 依 `pointerId` 追蹤接觸點，在 SVG 地圖座標計算兩指中心與縮放錨點；觸控不依螢幕寬度啟用。處理雙指轉單指、第三指、取消、失焦、視窗大小改變及縮放後誤點，縮放上下限與按鈕一致為 0.65–2.8。手機頁首把角色按鈕排在標語之後，避免擠壓品牌；原有科別與相簿視窗沿用。

基本檢查：`node tests/player-gestures.cjs`、三份 JavaScript 的 `node --check`、`python3 tests/validate_curriculum.py`。

瀏覽器檢查：在已有 Playwright 與 Chromium 的環境設定 `NODE_PATH`，執行 `node tests/browser-player-gestures.cjs`；可透過 `CAMPUS_BASE_URL` 指定預覽網址（預設 `http://127.0.0.1:8013/115/`）。測試包含八科實際旅程、可行走區域取樣、取消／改選不跳位置、角色儲存、課程／搜尋入口、原有商經遊戲與金幣、Chromium 原生雙指觸控與錨點、轉單指、取消、失焦、重設、誤點抑制、上限，以及手機與 iPad 尺寸的橫直版面。這些是 Chromium 模擬，不能取代 iPhone／iPad Safari 實機測試。

此功能維持 `codex/player-ipad-pinch` 草稿分支，未部署正式 GitHub Pages。
